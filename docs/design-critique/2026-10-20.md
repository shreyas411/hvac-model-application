## Summary — top themes

1. **Black outlines everywhere (root cause found).** Cards, tables, filter bars, the account button and secondary buttons are drawn with a near-black 1px border. `index.css` has no base `border-color` rule. In Tailwind v4 a bare `border` falls back to `currentColor` (the dark text colour), and shadcn's usual `* { border-color: var(--border) }` is missing. Affects every screen (~50 component files use `border`). This is most of the "too high contrast" feeling.
2. **Monospace used for data, not just codes.** 187 `font-mono` uses: job/invoice/quote numbers, dates, money, counts, postcodes, even "2 sites". Bold black mono on every table row reads as heavy and technical. Reserve mono for IDs; use tabular-nums in the normal font for money/dates.
3. **Too many loud, saturated elements per screen.** Big coloured mono money figures (green £260.00, red £2,205.00), bold-red numerals on KPI tiles, an all-orange "On Hold" status button, and red *Delete* + green *Record Payment* on every row.
4. **Wrong or risky actions offered.** Record Payment on **Void** invoices; Delete next to Accept on Sent quotations; Delete on void invoices.
5. **Small targets and small type, especially on phone.** Buttons at ~28–30px desktop; mobile has 14–57 targets under 44px per screen; inputs under 16px (iOS zooms on focus); dispatch uses 10–11px text.
6. **Layout breaks on narrow screens and with long data.** Horizontal page scroll on dashboard (43px over at 390 wide, and also a horizontal scrollbar at desktop), dispatch (33px), customers (68px); long unbroken job titles overflow the Action Queue card.

## Global tokens (`frontend/src/index.css`)

| Token / rule | Now | Proposed |
|---|---|---|
| base `border-color` | missing → `currentColor` (near-black) | add `@layer base { * { border-color: var(--border) } }` — one line, fixes theme 1 everywhere |
| `--border` | oklch(0.929 …) | fine for dividers; make `--input` slightly darker (≈ 0.87) so fields stay clearly visible once outlines go soft |
| `--foreground` | oklch(0.208) | ≈ 0.27 (still far above AA on the off-white page) |
| `--muted-foreground` | oklch(0.554) | check numerically; dates in grey ("17 Nov 2026") look borderline on white. Don't lighten, may need to darken slightly |
| `--background` | oklch(0.984) | already off-white — keep |
| `--primary` | saturated blue, used for solid fills on large areas (active nav, many buttons) | keep for primary action; use `primary/10` tint + dark text for the active nav item |

## Suggested order of work

1. **Global tokens + base border rule** (`index.css`), then re-measure contrast numerically. One commit, biggest effect.
2. **Type**: mono only for codes; `tabular-nums` elsewhere. Drop weight from 700 to 500/600 in tables.
3. **Risky actions** (I1, Q1, K1, C1): hide invalid actions, move Delete into a "⋯" menu, use `AlertDialog`. These are P0/P1 and need a quick API check for I1.
4. **Technician portal** (T1–T5), the phone-first screen.
5. **Overflow / mobile tables** (D1, D2, C2).
6. Second critique pass for the uncovered roles, dark mode, public quote page, offline, and quick-create modals.
